# Evolution of Developers Workflow

The simplest way to see the evolution is:
> Old workflow: Human writes → machine executes.
> Modern AI workflow: Human specifies → agent plans → tools execute → human reviews.
> Future workflow: Human defines systems/constraints → agents continuously operate parts of the system.
